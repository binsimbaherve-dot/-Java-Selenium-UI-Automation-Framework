# Project 1: Java Selenium UI Automation Framework (Core Foundation)

A complete UI automation framework for a sample web application (login, forms, tables).

## Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Git

## Scope (What this framework will test)
- Login flows
- Forms
- Tables

## Framework Features (Must Include)
- Page Object Model (POM)
- TestNG annotations (@BeforeSuite, @Test, @AfterSuite)
- config.properties for environment/config
- Parallel test execution
- HTML test reports
